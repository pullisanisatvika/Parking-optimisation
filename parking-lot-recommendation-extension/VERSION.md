# Version Notes

## Version 1: Parking-Lot Recommendation Baseline
This repository preserves the original lot-level parking recommendation system.

The system selects a parking lot based on the current project logic, such as travel time, walking distance or walking time, parking cost, and availability where supported by the baseline workflows.

This version does not include individual parking spot assignment.

## Planned Version 2: Dynamic Parking-Spot Assignment
The next project version will extend this baseline by modeling each parking spot as a candidate with its own availability, internal driving time, internal walking time, external walking time, and parking cost.
